# Abdeckung nach dem klickbaren Prototyp

Grundlage ist die Matrix in `../review-20261119/ABDECKUNGSMATRIX.md`. Sie beschreibt den gelesenen V1-Bestand. Diese Datei sagt, was der Prototyp unter `abnahme-20261119` als lokale Demo zeigt. «Demo» heisst: im Browser nachvollziehbar, mit erfundenen Daten, ohne externe Aktion.

| Bereich | Stand | Grenze |
| --- | --- | --- |
| Übersicht: letzte Arbeit fortsetzen, Aufgabe beginnen, zwei offene Punkte | Demo | Kein Test mit einer ungeübten Person |
| Akquise: Recherche und Import mit Dublette und fehlender E-Mail | Demo, simuliert | Keine echte Suche, keine Datei, kein Drive |
| Akquise: alle vollständigen wählen, leeren, bereits angeschrieben nicht vorausgewählt | Demo | Die Menge ist ein Beispiel, nicht 25/50/97/100 |
| Akquise: gemeinsames Briefing, persönliche Entwürfe | Demo | Texte werden lokal aus dem Briefing gebildet, nicht von einem Modell |
| Akquise: Prüfung je Person, Änderung entwertet nur diese Person, dann gemeinsame Bestätigung | Demo | Ein unklarer Fall ist fest als Beispiel eingebaut |
| Akquise: Einzelresultate | Demo, simuliert | Kein Versand |
| Newsletter: Kopie ohne Überschreiben, Bearbeiten und Vorschau synchron, Bilder, Links | Demo | Vorschau tippt mit, solange das Skript läuft |
| Newsletter: Prüfung, Mailchimp-Entwurf, Testmail | Demo, simuliert | Nichts verlässt den Browser |
| Social, Website, Bild, Video, Grafik | Demo mit eigener Ansicht und nächstem Schritt | Keine Konten, keine Veröffentlichung, kein Film, kein Upload |
| 3D | Entscheidung nötig | Im gelesenen V1-Bestand kein Modul. Die Ansicht sagt das und schlägt vor, keinen eigenen Einstieg zu bauen |
| Projekte: Kunde, Ziel, Konzept, Kampagne, Sprung zu Inhalt | Demo | Ein Beispielprojekt, keine Datenübernahme aus V1 |
| Bibliothek: Ordner unter Kunde/Projekt, Medien wählen | Demo | Kein echter Upload |
| Kalender: Plan und Rücksprung, externe Verbindung nur Vormerkung | Demo | Kein Schreibsync. Entscheidung, ob je geschrieben wird, bleibt offen |
| Einstellungen: Marke, Rollen-Vorschlag, Verbindungen | Demo | V1 hat kein Rollenfeld. Die drei Stufen sind ein Vorschlag |
| Lokales Merken, Fehler sichtbar, Auswahl und Entwurf überstehen Wechsel und Neuladen | Demo | Keine Cloud. «Gespeichert» wird nicht behauptet |
| Anmeldung, echte Rollen, Kundenweg zwischen Projekten und Akquise | Entscheidung nötig | Im Prototyp ein Beispielkonto ohne Anmeldung |
| V1-Laufzeit, Render, Versand, Merge | Offen und gesperrt | Dieser Prototyp ändert daran nichts |

Gestaltungsbasis: die von Martin mit «Sieht gut aus!» bestätigten Ansichten in `review-20261119`. Schriftstapel Arial, Helvetica, sans-serif, Laufweite normal. In diesem Export zeichnet Chrome Arimo, weil Arial fehlt.
